# Natural-language intake

- Users may speak naturally; do not require routing keywords.
- Treat the intake tier as a prediction. The Diff Gate is final.
- Ask only when the answer materially changes acceptance, scope, real-system use, cost or irreversible risk.
- Ask one question per round, with 2–3 mutually exclusive outcome choices and a recommended option in beginner language.
- Prefer acceptance and product-scope questions over technical choices.
- Record reversible assumptions instead of asking low-impact questions.
- One task has at most one primary UI Skill. Project rules and the design system override every Skill.
