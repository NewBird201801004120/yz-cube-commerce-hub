# Primary UI Skill routing

- `finesse-brief`: a new, underspecified product or application that needs product definition before UI work.
- `finesse-ui/brand`: new landing, brand, launch, portfolio or high-motion visual page.
- `finesse-ui/product`: new dashboard, workbench, settings or data-heavy product UI.
- `finesse-ui/commerce`: product detail, catalog, cart or checkout UI.
- `finesse-ui/h5`: mobile H5, activity page or app prototype.
- `design-review`: improve or audit an existing product interface without replacing its design system.
- `none`: backend, API, data, auth, billing or other non-visual tasks.

Never activate multiple primary Skills. A visual Skill cannot add dependencies, replace tokens or broaden scope without project approval.
