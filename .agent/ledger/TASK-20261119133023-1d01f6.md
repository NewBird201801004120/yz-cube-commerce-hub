# 本地化图片选择与文案补全

目标：修复组图选择弹窗长标题遮挡和选择身份，允许在商品编辑中基于当前图片及真实资料补齐缺失文案，经预览确认后应用到未保存编辑态。
验收：长标题正常换行，第二张及跨任务同slot可选，最多9张；取消不写商品；AI只补缺失标题/卖点/描述，保留人工编辑，加载与失败反馈明确，过期响应不覆盖新资料；owner和revision验证；本地接口及浏览器通过再部署。
范围：独立localization-copy-suggestions后端/测试及三入口注册，ProductEditor及独立建议组件/样式/API，listing-image-picker及局部workspace样式，相关文档。
非目标：修改冻结组图核心、推测真实SKU/材质/认证、自动保存、真实商品发布、修改仿真平台代码。
事实：仿真前端只传listingId，后端决定requestId。同requestId同内容replayed无新记录，异内容409；编辑商品不能保证生成新编号。明确新推送须新requestId，网络重试保留原编号。
