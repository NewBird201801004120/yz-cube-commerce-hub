# 统一待上架来源与跨店铺本地化

目标：一键上架、本地化共用仿真及调研来源；本地化额外选择授权店铺在售商品，独立编辑、转译和上架。
验收：共用来源一致；全部/仿真/调研/店铺筛选与分页；来源店铺不写入；编辑保存/取消/刷新和预览联动；跨币种不沿用售价；发布任务保护；生产与本地只读验证。
非目标：修改店铺商品的数据来源、真实发布商品、付费AI生成、重构组图核心。
范围：localization独立模块与测试，相关模块注册，商品工作区前端、来源列表、文案输入；必要部署脚本和记录。
假设：店铺只读接口权限以实际授权为准，失败明确呈现；已发布版本只读。
用户授权：已确认上述产品方向并要求实施，沿用main与生产交付授权；不以验收为由修改真实商品。
