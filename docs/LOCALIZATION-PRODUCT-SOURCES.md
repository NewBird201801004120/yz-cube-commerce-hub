# 商品来源与跨店本地化

## 页面范围

- 一键上架：仿真推送、市场调研导入的共用商品来源。
- 商品本地化：上述共用来源，以及已授权店铺的在售商品；默认全部，可筛选仿真、调研或某家店铺。
- 店铺商品：保持原有真实店铺商品查询，不并入待上架来源。

店铺来源仅调用 Shopee `get_item_list`（NORMAL）、`get_item_base_info`、需要时调用 `get_model_list`。打开商品会保存独立来源快照，内容不变时幂等复用；不写入来源店铺。不沿用来源店铺类目、属性、物流或仓库 ID，目标版本重新适配。

## 管理员接口

以下为已登录中台管理员使用的内部接口，不增加仿真发送方的接入要求；复用现有服务端会话与店铺授权。

### GET /api/v1/localization/shop-products

| 查询参数 | 类型 | 必填 | 含义 |
|---|---|---|---|
| shopId | string | 否 | 授权连接 ID；省略时读取全部连接正常的店铺 |
| offset | integer | 否 | 首次为 0；下一页使用响应 nextOffset |
| pageSize | integer | 否 | 默认20，1～50；全店查询按店铺均分读取配额 |

响应：`{items, nextOffset, hasMore, warnings}`。items 字段为 `key, shopId, shopName, region, itemId, title, image, status, currency`，实际读取到时附 `price, stock`。部分店铺读取失败时 warnings 明确列出；全部失败返回502。切换来源筛选必须从 offset=0 重新读取。页面累计展示已加载条数，并可继续加载，不代表全店商品总量。

### POST /api/v1/localization/shop-products/:shopId/:itemId/import

无请求体。shopId 为授权连接 ID；itemId 为真实 Shopee 商品编号字符串。仅接受仍在售（NORMAL）的商品，返回持久化 `LocalizationSource`。sourceSystem 固定 `shopee-shop`，sourceProductId 为连接ID与商品编号的组合。跨账号不可读取快照；来源店铺失联或商品不在售时拒绝导入。

快照保留商品标题、描述、主图、图文详情、规格图、最多两级规格、SKU、实际可读售价库存、重量尺寸。未读到的价格库存不会伪填零，待目标版本补齐。来源币种不同且没有目标币种最终售价时允许创建草稿，但售价留空，发布前仍须补齐。

### GET /api/v1/localization/sources

生产返回本账号共用来源。本地团队模式通过服务端会话同步中央来源与其受保护图片，保留已有本地版本编辑；远端读取失败明确报错，不以空列表冒充成功。本地编辑不会同步修改生产草稿或原店铺商品。

## 编辑与发布边界

- 编辑标题、卖点、描述、图片顺序、规格名称与选项、售价库存、重量尺寸时，手机预览联动；点击保存资料才更新当前草稿。取消、放弃离开不写入。
- 转译以已保存的当前文案与规格为输入，原始来源快照保留。来源店铺编号等追溯信息不作为需要写进商品描述的事实参数。图片像素不翻译。
- 同一来源、目标店铺、语言及用途复用已有版本。不同店铺、语言的版本独立保存。
- 有进行中、结果不明或已经创建远端商品的发布任务时，后端拒绝改写草稿；创建前失败可修正，再继续原任务。既有发布幂等、核对远端及失败恢复不变。

## 详情图片编辑

商品图片在SKU规格之前，支持拖拽文件或选择文件上传、移除与排序，已有图片及本次新增合计最多9张；PNG/JPEG/WebP单张不超过8MB。800×800或更高的正方形图片作为编辑建议，不强制裁切、拉伸或把800×800写成所有市场的发布硬要求。实际发布仍按目标市场限制和Shopee接口结果检查。

`POST /api/v1/localization/assets` 接收 `{data: "图片Base64，不含data URL前缀"}`，返回 `{url}`；复用管理员权限，素材按账号隔离。

`POST /api/v1/localization/listing-images/prepare` 接收 `{images:[{jobId:string,slotId:string}]}`，选取同一已完成组图任务中的1～9张图片，返回 `{urls:string[]}`。仅准备本账号私有素材，不修改商品来源或草稿，未完成、越权、重复图片和超过9张均拒绝。编辑态组图选择与文件上传均须点击保存资料才替换当前版本；取消不改已保存图片。
