# Listing 组图生成

## 本地使用

运行 `pnpm dev`，登录中台后进入：

- `/settings/ai`：配置图片理解/策划模型和生图模型。
- `/tools/listing`：上传原图、补充资料并生成组图。

API 地址填写完整版本前缀，例如 `https://api.openai.com/v1`。策划使用 OpenAI 兼容 Chat Completions（支持图片输入和 JSON 返回），生图使用参考图 `images/edits`。支持 base64 或公网 HTTPS 图片返回，图片会落盘保存。

两项配置可以使用同一服务商/密钥。可获取当前 API 的模型列表后选择，也可手动填写；不自动切换供应商。列表可见不代表具备图片编辑能力。文本连接测试和模型查询不等于实际出图成功。

## 资料与生成边界

- 必填一张产品原图：PNG、JPEG、WebP。
- 可补充最多五张图片、三个参数文件，支持 PDF、DOCX、XLSX、CSV、TXT、JSON、Markdown。
- 单个附件不超过 8MB，附件总计不超过 20MB；参数文件文本不超过四万字。扫描 PDF 没有文字层时请改传图片。
- 用户可补充产品名称、完整 SKU、品牌、视觉要求、市场、图片语言和产品说明；最多生成 4/6/8 张。品牌及主题色不固定。
- 按已提供资料策划核心卖点、功能、使用场景、结构、容量、尺寸等不同用途的图片；无补充依据的功能、尺寸、材质、内部结构、容量、颜色或配件内容跳过。
- AI 对资料的识别仍需运营核对。产品事实和生成提示词保存在任务详情中，可查看来源并调整单张提示词。
- 不绑定验货、竞品、选品评分和固定箱包/泰国模板；不自动写入真实店铺。

## 数据与运行

`LISTING_DATA_DIR` 指定持久化目录，默认是**服务进程当前目录**下的 `.local/listing`。团队开发脚本从仓库根启动；独立 API 服务应配置固定绝对路径。

该目录保存加密 API 配置、独立加密密钥、原始附件/提取文本、任务和图片；不能提交 Git。备份时须同时保存配置和加密密钥。当前本地开发的 AI 配置和生成历史属于本机，不会自动同步至其他同事或中央服务器；未来集中部署可使用服务器固定数据目录。

任务在服务端逐张执行，最多两个并行任务。刷新或切换菜单不打断已受理任务；页面按登录账号记住所选任务，回到页面自动恢复状态。首次进入优先展示运行中任务。主动点“新建组图”后的空白状态也会记住。未提交的附件和表单不跨刷新保存。

查询断网后按退避间隔自动重连；网络恢复、回到页面时立即补查。服务进程重启后保留完成图片，任务标为部分完成，可手动继续；不宣称自动续跑上游已经中断的生成。

“停止任务”会等待正在请求的图片返回并落盘，然后停止后续图片；不是撤销服务商已经接受的生成。之后可继续未完成图片。单张重生成严格只处理该张，整组继续跳过已成功图片。同一提交标识可安全重放，运行中相同资料也会返回原任务，避免重复创建。

单张成功重生成保留最多五个此前版本，可点击“还原上次”。生成失败时原图片仍保留。图片可按需点击“AI 检查”，调用配置的策划模型比较原图与结果，检查外观、标识、虚构参数和文字等，显示修改建议；结果仅供运营参考，不保证准确，不自动重生成。检查会产生模型用量。单张图片和整组 ZIP 均需登录且校验任务归属（共用中台账号可查看同一账号的任务）。

策划请求对连接失败和部分临时错误最多请求三次；生图仅对明确的 HTTP 429 限流拒绝做有限退避重试。生图网络中断、超时或 5xx 可能已经被服务商接受，保留错误并提示先核对用量后手动重试，避免盲目重复扣费。

策划会持久化品类约束、可见产品特征、整组共用视觉规范，并将其传入每一张生成请求。原图资料不足时可用安全的构图、可见特点和纹理等不同方案，但不为凑数编造背面、内部或规格；所选张数为上限。服装、电子、个护、家具等采用不同的事实约束，未知品类限制在可观察外观。品类识别、风格一致性和图片文字质量仍需真实样本验证。图片理解、策划和生图请求会把所上传资料发送到管理员配置的服务商。

## 验证

新增 HTTP 测试使用模拟 AI 返回，验证配置加密/掩码、权限、参考图片编辑请求、资料不足跳过、严格单张重试、幂等重放、停止后继续、限流退避、版本还原、按需 AI 检查、重启恢复、图片和 ZIP 下载；实际解析了 PDF、DOCX、XLSX、CSV 测试文件。

真实付费出图由用户完成 API 配置后验收，本轮未读取旧项目密钥、未发起真实生图。原型 `apps/web/public/interactive-preview.html` 与原选品项目保持不变。

## 复用来源

核心流程参照本机 `ai-scoring-unified/app/lib/vision-ai.mjs` 的参考图片编辑、外观保真及逐图生成，以及 `listing-job-state.mjs` 的图片槽位/失败续跑机制，改写为独立 Nest 服务。未复制验货数据库、个人配置或旧业务数据。

## 本轮浏览器验收

以隔离的假任务及受控模拟响应验证了首次加载失败后的自动恢复、刷新自动恢复、查询失败后的自动补查、停止/继续入口、单张重试参数、按需图片检查、图片还原入口和新建空白状态；检查 1920、1280、390 宽度无横向溢出。模拟结束移除路由拦截，未创建真实付费任务。证据不代表实际模型出图质量通过。

与旧选品工具的执行方式仍有有意差异：当前逐张生成，优先便于停止与控制用量；未引入旧项目每批三张并行。图片检查按需执行，不自动收费检查/修复。组图为方形 Listing 主图，不包含旧项目竖版详情图。

## 删除与资料核对

支持移除上传前原图、补充图片和参数文件。任务受理后的附件属于本次任务快照，不因左侧输入框变化而改变。

生成完成或暂停后，可删除单张图片或整组记录，须在页面确认。运行/检查中先停止或等待完成。单张删除后不再显示、下载、供本地化新引用或被整组重试重新生成；整组删除后不再出现在历史或可访问的任务接口中。记录采用逻辑删除，底层附件和图片暂留服务器，本页没有回收站；此操作不释放磁盘空间。已复制至本地化商品草稿的素材独立保存，不随源任务删除。

当前策划流程为上传 → 一次多模态策划 → 直接逐张出图，未提供策划预览确认、受理后补资料重策划。类型白名单现包含核心功能、使用说明和随附配件；新版强制要求主图及不超过100字符的SEO标题。张数为上限；不同用途和整组叙事由模型策划，程序无法独立证明营销覆盖完整。来源存在校验不等于事实准确性或每个提示词都绝无虚构。

一张白底图可作为外观参考生成主图和多种视觉设计，不要求每张成图都有一张源照片；但真实功能、参数、适用方式、配件等仍需产品说明、文件或补充图作为依据。只上传正面图也不足以精确还原背面和内部。当前代码会跳过缺证据内容，因而不保证得到内容完整且有销售说服力的一整组 Listing。

后续策划流程应在付费出图前提供商品信息核对、缺项提示、图片用途与文案预览、编辑/删除方案及补资料重策划。该流程升级尚未在本轮实现。

删除操作另以隔离任务验证了上传附件移除、取消不删除、逐张删除及计数更新、最后一张删除、整组删除后刷新仍为空、运行中删除禁用；390 与 1405 宽度无横向溢出。接口测试另外覆盖归属校验、下载排除、已删请求防重放和已删图片防重试。未删除用户真实任务。

## 营销组图规则 V2（2026-11-13）

- 目标是品牌视觉统一、核心卖点驱动、按商品动态排版。主图不再强制无文字；突出一个有依据的差异点，真实产品约占50%～65%，辅助功能仅在有证据时使用。各张图回答不同购买问题，避免用重复局部特写凑数。这些为模型策划约束，非像素级排版保证。
- SKU、品牌和视觉要求选填；视觉要求可指定配色、风格及品牌参考图文件名，不填时由模型根据品类与产品选择。没有绑定fortcamhub、深蓝科技风或任何固定品类。无Logo参考时不得虚构Logo；如需精确Logo，可在补充图中提供独立清晰素材，并在视觉要求中标明。
- XLSX提取所有工作表的文字，并保留表名和行号。模型按完整SKU优先匹配，再考虑型号/产品名称，识别冲突或未唯一匹配时应说明并放弃相关宣传；目前不是独立的人工参数验收或确定性Excel型号匹配引擎。大表超过4万字会拒绝，需用户保留相关范围，不静默截断。
- 明确约束前后镜头不同分辨率、355°旋转、WiFi/4G可选版本、未核实认证/追踪等，不得合并或擅自升级参数。可在结果查看卖点来源、选择理由、缺项与冲突说明。原图保真及语义准确性仍需人工复核。
- 无竞品参考时只做基于产品的买家需求推断，不自动联网调研、不宣称已分析真实竞品。生成后AI检查仍按需调用，非自动收费步骤。
- 同一策划请求生成SEO标题，与主图核心卖点呼应；菲律宾市场提示使用英文，其他市场用所选语言。代码硬校验非空及最多100个Unicode字符（包含空格），不合格时策划失败，尚不进入付费生图。语言、关键词效果及参数语义一致性为模型约束，发布前需人工确认。
- 所有新生成图片在本地等比缩放/留白至800×800，转sRGB JPG，JPEG质量从94开始有限下降，实测每张小于2,000,000字节。保留完整构图，不裁切、不拉伸、不重新调用模型。没有为旧图片批量重编码；还原旧版本按该版本文件原样显示。
- 新版整组ZIP包含当前成功图片、SEO-title.txt、核验说明.txt；单张下载仍仅下载该图。历史任务兼容原格式，不自动重策划或收费补标题。核验说明明确是AI整理结果，非人工验收或实测。

验证使用模拟模型返回与真实JPEG编码，覆盖主图/标题校验、缺依据功能剔除、多工作表提取、图片尺寸/字节检查、非方图留白不裁切、ZIP文本和图片内容，以及原有权限、停止、重试、版本还原和删除。未发起付费模型请求，新提示词的实际营销出图质量待用户用素材验证。

新版页面以隔离模拟任务验证SKU/品牌/视觉要求随提交传递、SEO标题与资料说明显示、ZIP下载入口，以及390/1405宽度无横向溢出。浏览器模拟已移除，没有提交真实付费任务。全项目74项测试通过，类型检查与原型基线校验通过。
