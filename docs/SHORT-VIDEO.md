# 商品短视频（团队本地开发）

在 `.env.team` 配置百炼 API Key、工作空间 ID 和地域，以及私有 OSS Bucket 的地域、名称和有 PutObject/GetObject 权限的凭据。配置项见 `.env.team.example`。百炼 Key、工作空间和地域必须一致。不要提交 `.env.team`，修改配置后重启 `pnpm dev`。这些设置只供本机团队开发模式使用，不代表已部署到共享服务器。

登录后进入“商品短视频”，选择店铺、读取在售商品并选择商品。页面展示商品首图、标题、商品属性和可展开的描述，兼容普通描述及扩展描述；扩展描述中的图片仅在接口提供图片链接时显示。选择后自动调用百炼 qwen-plus，根据标题、描述文字（最多 12000 字符）和商品属性生成英文卖点、风格、镜头方案及待确认事项；按画面设计英文文字与声音。自动分析与重新分析会产生文本模型调用费用；商品资料不完整、存在冲突或分析失败时，请人工核对或手动填写。确认方案并点击生成后，系统使用商品首图和完整提示词调用 `wan3.0-video-prime`，默认 10 秒、720P、1:1、有声，画面文字及配音使用英文。生成及 OSS 存储会产生费用。任务在本机 `.local/short-video-jobs.json` 保存；本地服务运行时每 15 秒查询并在成功后自动保存到 OSS。服务停止期间不处理，重启后继续；百炼任务与生成结果有 24 小时有效期，因此需及时启动服务。预览 URL 为一小时有效的 OSS 签名链接。生成视频及结果需人工审核。

提交结果未知时，先在百炼控制台检查任务再重新生成，避免重复计费。OSS 保存失败会自动重试。当前记录仅存在本机，非跨电脑共享；清理 `.local` 前需保留记录。百炼和 OSS 的真实调用需要用户自己的有效配置，示例配置本身不能使用。

新生成任务会保留发送给视频模型的完整提示词，可在生成记录中查看；旧任务没有记录提示词。百炼可能对视频提示词进一步改写。

生成记录中的“核对配置目标”重新读取任务对应的店铺和商品；接口未返回视频字段时无法确认既有视频，禁止继续。确认后可上传至 Shopee 媒体空间并查询转码；转码成功后再次确认店铺及商品才能关联。更新前中台再次检查原有视频与确认时一致，提交后按 Shopee 返回的视频播放地址读取商品核验。关联可能替换原有视频，实际行为尚未真实验证。

上传限制为最大 30 MB、10–60 秒；中台以 4 MB 分片转发。上传中断、提交超时或重启时保留“待确认”，不自动重试；已取得上传 ID 的任务可重新查询转码，关联提交后的结果可重新核验。商品视频在确认后发生变化时，需要重新核对，再关联已上传的视频。尚未取得上传 ID 的未知任务需要人工核查。

上传与关联依赖团队中台部署对应 API 代码，并更新 `deployment/server/nginx-aicbec.conf` 的分片请求体限制；仅更新本地代码时上传预检会提示中台尚未接入。正式部署和真实商品联调均需另行确认具体目标。
